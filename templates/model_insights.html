Module A — Mandi Price Prediction DSS

This module predicts the modal (typical) market price for a chosen commodity and market in a given month, using five independently trained models: Linear Regression, Random Forest, XGBoost, ARIMA (a classical time-series model), and an LSTM neural network. All five run in parallel on the Model Comparison page so a user can see how much the models agree.
