Module M1 + M6 · Built for the board

Reads the Arduino Uno node live over USB serial

The ingest endpoint, SQLite schema and threshold-based advisory engine (M5) are fully live, fed either by the real sensor node (Arduino Uno + pH probe + DHT11 + HW-080 soil sensor + 16x2 LCD) over USB serial, or by a demo simulator when no board is plugged in.

Every cycle is averaged over the last 10 readings and scored against a trained plant-health model, so the Sensor Node tab shows one clear healthy / needs-attention verdict, not just raw numbers.

  • Plug the Arduino Uno in, note its COM port (default COM6)
  • Set KRISHISENSE_HARDWARE_MODE=serial and KRISHISENSE_SERIAL_PORT before starting the server
  • pip install pyserial (already in requirements.txt)
  • Leave KRISHISENSE_HARDWARE_MODE unset (or =simulate) to fall back to the demo node
